# 《未登录的人》体验评审

以首次玩家和二周目玩家的视角，指出可复现的问题及其对体验的影响。评审请求本身只授权检查和报告；只有用户要求修改时才编辑游戏或文档。

## 依据

- 先读仓库 `AGENTS.md`、`docs/story-bible.md` 和本次涉及的章节流程；只在角色视觉相关时读 `docs/characters/`。
- 以实际运行的推荐 Web 版为主要体验依据；涉及双版本一致性时，对照 Ren'Py 原型。无法试玩的部分明确标为静态推断。
- 同类作品只比较人物关系、路线结构、信息呈现和交互节奏，不引入其人物、专有设定、情节、台词或美术标识。

## 评审重点

- UI：阅读层级、移动端触控与对比度、聊天界面是否传递剧情信息。
- 剧情：N 的语气与动机、主角行为、异常的证据链、伏笔与结局回收。
- 玩法：选项语义是否与后果一致，玩家能否亲自验证异常，分支是否值得重玩。
- 工程呈现：存档、菜单承诺、音画反馈和 Web/Ren'Py 关键线索是否一致。

按严重程度报告最重要的问题，给出节点或文件位置、玩家可感知的影响、具体改法和可观察的验收条件。区分已复现的缺陷、合理推断和创作取舍；不要把主观偏好写成客观错误。若用户要求多个方案，说明每个方案的范围、收益和代价，并明确推荐依据。
