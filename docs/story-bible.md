# 《未登录的人》故事圣经（v0.1）

## 一句话

一个习惯把一切归为巧合的普通高中生，在深夜与自称 N 的陌生账号聊天；她知道得太多，而聊天记录正在改写现实。

## 体验目标

让玩家先觉得 N 是一个有点欠、却很自然的人，再在普通对话里慢慢意识到：她并不应该能看见这些事。异常不靠解释堆砌，而由细节、沉默和界面失真构成。

## 角色

### 玩家 / 男主（暂未命名）

- 普通、会自嘲、遇到事先找合理解释。
- 不直接宣告孤独或失败，用“明天第一节是不是数学”“再打一局”这类小事体现。
- 不设固定外貌，方便玩家代入。

### N

- 说话自然，偶尔调侃，不是高冷谜语人。
- 知道许多不该知道的事，但从不长篇解释。
- 她想确认的不是“玩家会不会害怕”，而是“玩家是否愿意回应”。
- 她的真实身份在第一章不揭晓。

## 世界规则（第一章只暗示）

1. N 的账号在通常意义上并不在线。
2. 当玩家持续回应 N 时，设备时间与聊天记录会出现不一致。
3. 异常总以普通通信工具为入口：好友申请、输入状态、撤回记录、短信。
4. 玩家做出的回应风格会改变“谁能记住这段聊天”。

## 原创边界

参考作品只用于分析都市奇幻的节奏、日常感与悬念建立方式；本项目不使用其人物、专有设定、情节、世界观、原文台词或美术标识。
