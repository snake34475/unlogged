# N 角色母版（v0.1）

## 叙事定位

深夜通过陌生账号出现的女孩。她说话不冷、不端着，甚至有点欠；真正让人不安的是，她能在最日常的细节里说中不该知道的事。第一章只以 N 的账号身份存在，第二章才正式线下相见。

## 视觉锚点

- 年龄：18 岁
- 身形：健康偏瘦，普通女孩的体态，不做偶像式夸张比例
- 头发：及肩深赤褐发；室内接近黑色，受光时才显出铜红色发尾
- 眼睛：深棕色
- 服装：褪色蓝色牛仔外套、黑 T 恤、深色直筒裤、白色运动鞋
- 饰品：一枚细银戒指
- 气质：自然、利落、略带调侃；不是高冷神秘女神
- 色彩：海军蓝、炭灰、褪色牛仔蓝；铜红仅作身份识别的小面积点缀

## 母版

`game/images/characters/n/master_front.jpg` 是唯一锁定的正面全身中性参考。后续立绘必须保持脸型、发色层次、服装、身材比例和克制的表情基调。

## 素材优先级

1. 正面中性母版（已完成）
2. 第二章使用的半身 `normal / smile / tease / serious` 四张（已完成）
3. 特殊表情 `empty`（用于第一章结尾或异常状态）
4. 三视图（需要大量动态姿势或换装时再做）
5. Q 版表情（用于菜单、成就或轻喜剧交互时再做）
