# 男主角色母版（v0.1）

## 叙事定位

普通高中毕业班男生，习惯用玩笑和拖延把尴尬收起来。不是“隐藏的完美主角”，也不是纯粹的失败者；他最初只是比别人更容易把不对劲的事解释成巧合。第一章保留“我”的称呼，方便玩家代入。

## 视觉锚点

- 年龄：18 岁
- 身形：偏瘦、普通身高，不做偶像型比例
- 头发：短黑发，稍微不服帖
- 眼睛：深棕色；轻微疲惫感，但不阴郁
- 服装：深炭灰连帽外套、米白 T 恤、深蓝牛仔裤、帆布鞋
- 气质：克制、普通、警觉起来时才显出锐利
- 色彩：炭灰、藏蓝、低饱和冷色；不使用 N 的红色识别色

## 素材优先级

1. 正面中性母版（已完成）
2. 半身 normal / surprised / uneasy 三张，用在第二章第一次线下相遇
3. 三视图（只有要做换装、姿势或大量立绘时才制作）
4. Q 版表情（只在做系统提示、成就或轻喜剧演出时制作）

当前第一章是聊天叙事，不需要男主全身立绘入场；母版用于统一头像和后续资产即可。
