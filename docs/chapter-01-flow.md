# 第一章《未登录的人》流程

```text
开场：23:47 / 选择今晚做什么
  └─ N 发来好友申请
       └─ 选择：同意、拒绝、查看资料
            └─ N 知道玩家刚刚打开了游戏
                 └─ 选择：追问、反击、回避
                      └─ N 提到白色外套的女孩
                           └─ 选择：相信、怀疑、沉默
                                ├─ 信任最高 → END 01「明天见」
                                ├─ 好奇最高 → END 02「23:47」
                                └─ 回避最高 → END 03「她从未存在」
```

状态不会在 UI 中显示。第一章的选择只改变倾向与局部文本，后续章节可继承这些变量。
